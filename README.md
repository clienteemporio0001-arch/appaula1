# ASTRO CALC 🚀
Calculadora React Native + Expo 54 + TypeScript para Web, Android e iOS.

## Execução
Instale Node 20.19+ e npm. Execute `npm install` e `npm run web`. Testes: `npm run check` e `npm test`. Exportação: `npm run export:web`.

## Publicação web
Em **Settings → Pages → Build and deployment → Source**, selecione **GitHub Actions**. O workflow `.github/workflows/web.yml` compila e publica após push na main. Endereço previsto: https://clienteemporio0001-arch.github.io/appaula1/ (não confirmado até o deployment ter sucesso).

## Funcionalidades
Operações básicas, decimais, porcentagens, negativos, histórico em memória, teclado físico na Web, layout neon e astronauta vetorial. Nenhum backend. O histórico é perdido ao recarregar. APK e iOS ficam para fases futuras (EAS Build, certificados e Apple Developer para distribuição iOS).
